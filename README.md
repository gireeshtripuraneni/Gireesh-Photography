Gireesh Photography Showcase
A minimalist, high-performance photography portfolio showcasing a curated collection of temples, architecture, landscapes, and portraits. This project serves as a digital gallery for my work, emphasizing perspective and post-processing in mobile photography.

View Live Site

📸 About the Work
This portfolio represents a commitment to the craft of image-making. My philosophy centers on the idea that a unique perspective and thoughtful framing can elevate mobile photography into something genuine and significant.

Highlight: My photographic journey includes being featured by the Royal Canadian Mint, reflecting a constant drive for artistic development and technical improvement.

🛠️ Technical Stack
Frontend: HTML5, CSS3 (Modern Dark Theme), JavaScript

Animations: AOS (Animate On Scroll) for smooth element entries.

Lightbox: GLightbox for a premium, touch-friendly full-screen viewing experience.

Deployment: Hosted via GitHub Pages.

🚀 Key Features
Responsive Design: Fully optimized for mobile, tablet, and desktop viewing.

Performance Optimized: Uses modern CSS techniques and lazy-loading for fast image delivery.

Modern UI: Deep charcoal aesthetic with glassmorphism navigation to keep the focus on the photography.

Micro-interactions: Interactive hover states and smooth scrolling for an immersive user experience.
